# PY32F030 低功耗设计指南

## 功耗等级概述

| 工作模式 | 功耗 | 说明 |
|---------|------|------|
| 正常运行(8MHz) | ~2-3mA | 主频运行，所有外设可用 |
| Sleep模式 | ~300-500µA | CPU休眠，外设工作 |
| Stop模式 | ~10-50µA | 仅RTC/WakeUp可用 |
| Standby模式 | ~4.5µA | 超低功耗，仅RTC/外部引脚唤醒 |

## 实现4.5µA超低功耗的核心思路

### 1. 硬件准备
- **GPIO配置**：所有GPIO设为下拉输入（浮动会增加功耗）
- **外设关闭**：关闭UART、SPI、I2C等不需要的外设
- **时钟配置**：Standby模式自动停止所有时钟
- **电源管理**：使用内部稳压器，取消外部去耦

### 2. 软件实现步骤

#### 初始化阶段
1. 关闭所有外设时钟
2. 配置所有GPIO为下拉输入或推挽输出低电平
3. 初始化RTC或外部唤醒引脚
4. 配置唤醒源（RTC秒中断或WakeUp引脚）

#### 进入低功耗阶段
1. 禁用所有中断（除唤醒源）
2. 清除待处理中断标志
3. 执行Standby进入指令
4. MCU进入Standby模式（~4.5µA）

#### 唤醒后处理
1. MCU从Standby复位重启
2. 重新初始化系统
3. 执行业务逻辑
4. 重新进入低功耗

### 3. 关键配置点

**RCC时钟**
```
- 关闭HSE、LSE时钟
- HSI保持（Standby中停止）
- 关闭APB1/APB2外设时钟
```

**GPIO配置**
```
- PA、PB所有端口 → GPIO_MODE_INPUT, GPIO_PUPD_DOWN
- 或设为输出低电平状态
- 避免浮动输入导致漏电
```

**EXTI/RTC唤醒**
```
- 配置RTC秒钟中断唤醒（周期性唤醒）
- 或配置PA0外部引脚唤醒（事件唤醒）
- 设置唤醒源前必须启用相应中断
```

**进入Standby**
```
- 清空EXTI待处理标志位
- 设置PWR_CTLR寄存器的STBMOD/CWUF位
- 执行__WFI()指令
```

### 4. 功耗优化细节

| 项目 | 当前状态 | 优化 | 节省 |
|------|---------|------|------|
| GPIO泄漏 | 浮动输入 | 下拉输入 | ~100-200µA |
| 外设时钟 | 全开 | 关闭所有 | ~500-800µA |
| 内核 | 运行 | Standby停止 | ~2mA |
| 稳压器 | 常规 | Standby关闭 | ~200-400µA |

## 注意事项

1. **Standby模式不保存RAM数据** → 需要RTC或NVRAM保存必要数据
2. **复位会重新执行代码** → main()会从头开始，需要检测复位原因（RTC或外部唤醒）
3. **唤醒延迟** → Standby到完全运行需要~100ms
4. **调试困难** → Standby会断开调试接口，需要特殊配置才能调试

## 应用场景

- **IoT传感器**：定期采集数据，长时间待机
- **无线节点**：低功耗无线通信
- **环境监测**：电池供电，周期性上报
- **门窗传感器**：长期待机，事件唤醒
